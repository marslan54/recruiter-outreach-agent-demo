# Recruiter Outreach Agent: demo

**Live page:** https://marslan54.github.io/recruiter-outreach-agent-demo/

A recorded end-to-end run of an AI recruiter outreach agent built with n8n. It imports contacts, writes personalised
emails with an LLM, gets each one approved in Slack, sends them from Gmail with follow-ups, classifies every reply,
stops on any response or opt-out, and reports the results.

This repository holds only the static demo page. The workflows and source code are in a private repository and are
available on request. The sample brand, recruiters and studios are fictional.
